# ربات فروشگاه اکانت هوش مصنوعی 🤖

ربات تلگرام فارسی برای فروش اکانت‌های هوش مصنوعی (شروع با جمینای).
پرداخت **کارت‌به‌کارت با تأیید دستی ادمین** و تحویل **خودکار** از فایل موجودی.

## روش کار

1. خریدار با `/start` محصول را انتخاب می‌کند
2. ربات شماره کارت را نشان می‌دهد و خریدار عکس رسید را می‌فرستد
3. عکس رسید برای ادمین فوروارد می‌شود با دکمه‌های **تأیید** / **رد**
4. با تأیید ادمین، اولین اکانت استفاده‌نشده از فایل موجودی برای خریدار ارسال می‌شود و آن خط به فایل `used_...txt` منتقل می‌گردد
5. با رد ادمین، به خریدار اطلاع داده می‌شود

دستور `/stock` (فقط ادمین) موجودی باقی‌مانده هر محصول را نشان می‌دهد.

## راه‌اندازی قدم‌به‌قدم

### ۱. ساخت بات و گرفتن توکن
1. در تلگرام به `BotFather@` پیام بده و دستور `/newbot` را بفرست
2. اسم و یوزرنیم بات را انتخاب کن (یوزرنیم باید آخرش `bot` باشد)
3. **توکن** را نگه دار (محرمانه!)

### ۲. پیدا کردن آیدی عددی ادمین
به ربات `userinfobot@` پیام بده؛ عددی که برمی‌گرداند همان `ADMIN_ID` است.

### ۳. ساخت فایل `.env`
```bash
cp .env.example .env
```
بعد فایل `.env` را باز کن و هر چهار مقدار را پر کن:
- `BOT_TOKEN` — توکن مرحله ۱
- `ADMIN_ID` — آیدی عددی مرحله ۲
- `CARD_NUMBER` — شماره کارت برای واریز
- `CARD_HOLDER_NAME` — نام صاحب کارت

### ۴. شارژ موجودی
فایل `stock/gemini.txt` را باز کن؛ خطوط نمونه (FAKE-...) را پاک کن و
**هر خط = یک اکانت** بنویس. مثلاً:
```
user1@example.com | pass123
user2@example.com | pass456
```
خط خالی و خطی که با `#` شروع شود نادیده گرفته می‌شود.

### ۵. تعیین قیمت
در فایل `config.py` مقدار `price` هر محصول را به تومان بنویس (جای `0`).

### ۶. نصب و اجرا (روی کامپیوتر خودت)
```bash
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```
ربات در حالت **polling** کار می‌کند؛ نیازی به وب‌هوک، دامنه یا پورت باز نیست.

## افزودن محصول جدید
1. در `config.py` به لیست `PRODUCTS` یک دیکشنری جدید اضافه کن (`key` انگلیسی و یکتا)
2. فایل موجودی‌اش را در پوشه `stock/` بساز، مثلاً `stock/chatgpt.txt`
3. ربات را ری‌استارت کن

## دیپلوی روی Railway (اجرای ۲۴ ساعته)
1. کد را در یک ریپوی گیت‌هاب بگذار
2. در [railway.app](https://railway.app) پروژه جدید بساز و ریپو را وصل کن
   (فایل `railway.json` دستور اجرا را مشخص کرده است)
3. در بخش **Variables** همان چهار متغیر `.env` را اضافه کن:
   `BOT_TOKEN` ،`ADMIN_ID` ،`CARD_NUMBER` ،`CARD_HOLDER_NAME`
4. Deploy کن — ربات بالا می‌آید و با polling کار می‌کند

> نکته: چون ربات polling است، فقط **یک نمونه** (instance) باید اجرا شود؛
> اجرای همزمان دو نمونه باعث خطای `Conflict: terminated by other getUpdates request` می‌شود.

## ساختار فایل‌ها
```
gemini-shop-bot/
├── bot.py              # کد اصلی ربات
├── config.py           # تنظیمات و لیست محصولات
├── requirements.txt    # وابستگی‌ها
├── .env.example        # نمونه متغیرهای محیطی
├── railway.json        # تنظیمات دیپلوی Railway
├── README.md           # همین راهنما
└── stock/
    └── gemini.txt      # موجودی اکانت‌ها (هر خط = یک اکانت)
```
